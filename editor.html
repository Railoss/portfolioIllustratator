Опубликовать тексты

Правки готовы. Осталось сохранить их в твоём GitHub.

  1. Скопируй готовые тексты.
  2. Открой файл на GitHub.Открыть GitHub ↗

    В поле с текстом нажми Ctrl+A, затем Ctrl+V. На Mac — ⌘A и ⌘V.

  3. Сохрани изменение.

    Нажми «Commit changes…», выбери ветку main и подтверди «Commit changes». Сайт обновится после публикации GitHub Pages.

Если копирование не сработало

Сохранить изменения сможет только владелец репозитория или пользователь с доступом к нему.

Вернуть опубликованные тексты?

Текущий черновик будет заменён текстами с сайта. Перед этим можно скачать его копию.
