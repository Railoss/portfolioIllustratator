# portfolioIllustratator

Портфолио коммерческого векторного иллюстратора.

Исходники сайта подготовлены для GitHub Pages.

## Редактор текстов

Откройте `editor.html` на опубликованном сайте. В редакторе доступны тексты
главной страницы, всех проектов, подписи изображений, разделов и кнопок.
Правки автоматически сохраняются в браузере и видны в предпросмотре.
Публичный сайт читает только опубликованный `site-text.json`.

Для публикации нажмите «Опубликовать», скопируйте готовые правки и откройте
предложенную страницу GitHub. Замените содержимое `site-text.json` и сохраните
изменение в `main` через «Commit changes». GitHub Pages опубликует обновление.
Для сохранения нужен доступ на запись к этому репозиторию. Пароли и токены
в редактор не вводятся.

Черновик можно скачать и перенести на другое устройство через «Загрузить
черновик». Если браузер не разрешает локальное сохранение, скачайте копию
перед закрытием редактора. При новых изменениях на сайте редактор сохраняет
ваши изменённые поля и подхватывает остальные опубликованные тексты.
