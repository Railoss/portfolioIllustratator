# portfolioIllustratator

Портфолио коммерческого векторного иллюстратора.

Исходники сайта подготовлены для GitHub Pages.

## Тексты

Сайт загружает только опубликованный `site-text.json`. Публичного редактора,
поддержки локальных черновиков и режима предпросмотра на сайте нет.

Тексты можно подготовить в отдельном локальном редакторе или изменить
`site-text.json` через GitHub. Для публикации нужен доступ на запись
к репозиторию. После сохранения в `main` GitHub Pages обновит сайт.
